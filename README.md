# UntrackGPT

ChatGPT (`chatgpt.com`) の回答内の引用リンクや、コピーされたテキストに含まれる不要なトラッキングパラメータを自動的に除去するChrome拡張機能です。

## 主な機能

- **表示リンクの自動クリーンアップ**: ページ内のすべてのリンク (`<a>` タグ) から、不要なクエリパラメータをリアルタイムで削除します。
- **動的パラメータ付与の防止**: ユーザーがリンクをクリックした瞬間に動的に追加されるパラメータも、クリックイベントをフックして除去します。
- **テキストコピー時のクリーンアップ**:
  - **ブラウザ標準のコピー操作**: ユーザーがテキストを範囲選択してコピーした際、URL内のトラッキングパラメータをクリーンアップします。
  - **ChatGPTアプリ内ボタンからのコピー**: ChatGPTの「回答をコピー」ボタンや「共有」などのJavaScriptからのコピーに対しても、Clipboard API (`Clipboard.prototype.write` および `writeText`) をフックして確実にパラメータを削除します。

## 削除対象のパラメータ

- `utm_` で始まるすべてのパラメータ (例: `utm_source`, `utm_medium`, `utm_campaign` など)
- 変則的なソースパラメータ (例: `ut_source`, `utsources` など)
- 値が `chatgpt.com` となっているクエリパラメータ

## インストール方法

本拡張機能は、Chromeウェブストアを経由せずローカル環境から「パッケージ化されていない拡張機能」として読み込んで使用します。

1. このフォルダをローカルに保存します。
2. Google Chromeを開き、アドレスバーに `chrome://extensions/` と入力して拡張機能管理ページを開きます。
3. 画面右上にある **「デベロッパー モード」** のスイッチをオンにします。
4. 画面左上に表示される **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
5. 本プロジェクトのフォルダ（`manifest.json` が含まれているフォルダ）を選択します。
6. インストール完了後、`chatgpt.com` のページをリロードすると自動的に有効になります。

## ファイル構成と役割

- `manifest.json`: 拡張機能の設定ファイル（Manifest V3）。`chatgpt.com` で動作するように設定されています。
- `content.js`: WebページのDOM構造を監視し、表示されているリンクをクリーンアップします。また通常のコピー操作を監視します。
- `inject.js`: ページの実行コンテキスト（`MAIN` ワールド）に直接注入され、ブラウザの Clipboard API を書き換えることで、JavaScript経由のコピーデータをクリーンアップします。
